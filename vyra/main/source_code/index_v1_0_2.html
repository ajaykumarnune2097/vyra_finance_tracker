Cloud data backup & test controls

Transactions are stored in the shared VYRA Google Sheet. Export a JSON backup before any test reset. The reset action clears the shared Transactions sheet, so use it only during testing and only when both users agree.

Transaction deletion is disabled

For safety, this app does not provide a button that can erase all shared transactions. If a reset is genuinely required, download a full JSON backup first, confirm with Rahul, then delete transaction rows directly in the Google Sheet while keeping the header row. The app-side delete endpoint is also disabled.

Important notes

  • Transactions are shared through the VYRA Google Sheet.
  • No automatic connection to Mosambi, Zomato, Swiggy, Ownly or OrderMatic. Enter daily totals manually.
  • This is an operational tracker, not accounting/tax software. Verify figures before relying on reports.
